# PMDS Social Agent

An early-stage project to help PMDS create social media posts. The proposed assistant would take a brief, links and images through Telegram, prepare an editable post using the existing Figma template, and provide a separate caption for human review.

The intended stack is Python and LangChain. The Figma integration and detailed workflow still need to be validated; there is no implementation yet.

See [PROJECT_OUTLINE.md](PROJECT_OUTLINE.md) for the proposed direction and [TEAM_WORKFLOW.md](TEAM_WORKFLOW.md) for how the team will collaborate.
